# Financial & Weather Data Regression Analysis

Репозиторий содержит исследовательские и учебные проекты по анализу временных рядов, разведочному анализу данных (EDA) и построению регрессионных моделей.

#1. Регрессионный анализ и прогнозирование котировок акций
* **Файлы:** Модули обработки и анализа финансовых данных (`test.ipynb`, `graph.ipynb`, `mathmod.ipynb`, `progmod.ipynb`, `cwfc.csv`)
* **Стек:** `Python`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib / Seaborn`, `Statsmodels`
* **Что реализовано:**
  * Сбор, агрегация и очистка исторических финансовых данных и котировок.
  * Разведочный анализ данных (EDA), обработка пропусков, генерация новых признаков (Feature Engineering).
  * Анализ и устранение мультиколлинеарности между признаками.
  * Обучение и сравнительная оценка регрессионных моделей, анализ метрик качества ($R^2$, MSE, RMSE).

#2. Учебная практика: Прогнозирование метеорологических показателей
* **Файл:** Модель анализа погодных данных (`regression_weatger.ipynb`, `weatherHistory.csv`)
* **Стек:** `Python`, `Pandas`, `Scikit-learn`, `SciPy`
* **Что реализовано:**
  * Статистический анализ временных рядов метеорологических параметров.
  * Исследование корреляций и оценок взаимосвязи между климатическими факторами.
  * Построение регрессионной модели для прогнозирования целевой переменной.
